# Super Sonic Delivery

Two apps in one repo. Read the guide for the folder you are working in:
- `frontend/CLAUDE.md` – React app: design rules, folder structure, mock data, business rules shown in the UI.
- `backend/CLAUDE.md` – Express + PostgreSQL API: `frontend/src/mock/mock.js` is the spec, coding and security rules.

Shared references: `frontend/DESIGN.md` (design system), `backend/db/schema.sql` (database, ERD v7),
`docs/erd/SonicDelivery_ERD_v6_MySQL.sql` (original export, reference only).

Explain decisions in beginner-friendly language (student capstone, defended in a presentation).
Don't commit `.env` files or keys. Don't push unless asked.
